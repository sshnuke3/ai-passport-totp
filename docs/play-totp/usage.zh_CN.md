TotpPassport 使用方法
=====================

全程只需要两个按键：上、下、确定（OK）。
本文按实际操作顺序写，不按功能分类。


一、烧录固件
------------
用 FoloToy 的 web-flasher，选择本项目提供的整包固件，偏移填 0x0。

**一定烧整包，不要单独烧 app 分区。**
整包 = bootloader + 分区表 + app 三段合并；单独烧 app 会覆盖掉 bootloader，
设备开不了机。

烧完按任意键，设备会进入菜单。用上下键找到 TOTP 项，按 OK 进入。


二、第一次使用：录入账户
------------------------
首次进入 TOTP 页面时，设备没有账户，会自动开启一个 Wi-Fi 热点。屏幕上会显示
三行引导：

    1. 手机连 Wi-Fi: TotpPassport
    2. 浏览器打开 http://192.168.4.1
    3. 粘贴 otpauth:// 链接

按提示操作：

  1. 手机连上名为 **TotpPassport** 的 Wi-Fi。
     这个热点**没有密码**，这是正常的。
  2. 打开浏览器访问 **http://192.168.4.1**
     （部分手机会提示「无法访问互联网」，选「仍然继续」即可，
     因为这个地址不联网）。
  3. 网页上有个「otpauth 链接」输入框。

**从哪拿这个链接？**
去你要登录的那个网站的两步验证设置页。GitHub 是：
头像 → Settings → Password and authentication → 找到 Two-factor
authentication → 那里有 "setup key"，点开能看到一段以
`otpauth://totp/` 开头的文本。

把整段粘进去，点「添加账户」。
**一次可以粘多个，一行一个**，会批量添加。

  4. 顺手把家庭 Wi-Fi 填进下面的表单（SSID + 密码），点「保存并校时」。
     设备会用它静默校准时间，校完立刻断开。这是以后开机不用手动校时的前提。
     填了家庭 Wi-Fi 后，设备**不会再开热点**，改走 STA 模式联网。

  5. 点页面底部「完成，返回设备」，回到设备按 OK 关闭门户。


三、日常使用
------------
  · **看某个账户的码**：上下键选中该行，按 OK 进详情页，看大字号验证码。
  · **切下一个账户**：详情页里按上下键直接切，不用回列表。
  · **回列表**：详情页按 OK。
  · **刷新验证码**：不用管，30 秒自动换一次，进度条走完就换。
  · **最后 5 秒**：验证码变红，提示赶紧用。

如果状态行显示红色的**「未校时」**，说明设备时间不可信，码大概率是错的。
按上下键选「重新校时」，按 OK，等十几秒。校不上的话检查家庭 Wi-Fi 配置。


四、设置 PIN 锁（防肩窥）
------------------------
列表底部选「设置 PIN 锁」，按 OK：

  · **上下键**：改当前位的数字（上一位变 9，下一位……循环）
  · **OK**：确认这一位，移到下一位
  · **长按上/下**：提交

想设几位就输几位，输够 4 位后长按上/下提交即可。
然后再输一遍确认，防止手滑。

设置完成后：
  · 每次冷启动进 TOTP 页面都要先输 PIN。
  · **无操作 30 秒自动息屏**，屏幕切到锁屏态，必须重新输 PIN。
    未设 PIN 时不会息屏。

**PIN 输错 5 次锁 5 分钟。**
锁定状态存在设备里，**断电重启也还是锁着的**，只能等时间到。

输 PIN 时屏幕只显示圆点个数（● ● ● ●），不显示真实数字——防肩窥。


五、导出与备份
--------------
录入账户时开的那个网页（http://192.168.4.1）上有两个入口：

**「导出全部账户（明文）」**
下载一个 txt，里面是标准 otpauth 链接列表。
用途：换设备时重新导入，或者导到电脑上做记录。

⚠️ 这是明文文件，任何拿到的人都能看到全部密钥。用完请立刻转存并删除。
⚠️ 导出不需要输入 PIN——因为 SoftAP 本身就是开放网络。

**「下载加密备份」**
需要你自己设置一个备份口令，下载 .backup 文件。
文件里是 AES-256 加密的账户数据，解密口令就是你在网页上填的那个。

用途：设备丢了、密钥要恢复的时候用。

⚠️ **口令丢了就解不开，没有后门。** 建议用一串你记得住但不常见的口令。
⚠️ 目前这个备份**只能导出、还不能导入**——设备真丢了的话，
   暂时得靠上面的明文导出，或者手工重录。补导入端是计划中的事。


六、完整按键表
--------------
    页面          上 / 下            OK              长按上/下
    ─────────────────────────────────────────────────────────────
    列表          上下选择            进入详情/执行动作   —
    详情          切换账户            返回列表          —
    门户          —                  关闭门户          —
    PIN 屏        改当前位数字        确认并移到下一位   提交

    任意页面：长按 OK = 返回主菜单（这是设备的全局行为）


七、遇到问题
------------
**页面打不开 / 提示无法访问互联网**
  正常。192.168.4.1 不联网，选「仍然继续」或关闭 WLAN 检查。

**校时总是失败**
  确认填的 Wi-Fi 是在 2.4G 频段（ESP32-C3 只支持 2.4G），
  密码别填错。校时需要设备能连上 NTP 服务器，
  公司/学校的 Wi-Fi 如果需要网页认证也可能失败。

**码和手机上不一致**
  先看状态行是不是「已校时」。如果显示「未校时」，
  说明设备时间偏了，码当然不一样，先重新校时。
  校时之后还不一致，请开 issue 并附上：
  账户的算法（SHA1/SHA256/SHA512）、位数、周期。

**PIN 忘了**
  只能恢复出厂设置（NVS 会一起清掉，账户和 PIN 都没了）。
  这就是「无后门」的代价。

**设备一直开热点**
  说明录入账户时家庭 Wi-Fi 没保存成功。
  重新连热点进网页，填好 Wi-Fi，点「保存并校时」。
